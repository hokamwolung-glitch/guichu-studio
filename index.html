导入与编辑歌词

可粘贴普通歌词、LRC 或 SRT。普通文本按每字间隔排列；带时间戳的歌词保留原时间，并将每句中的字词均匀分配。增强 LRC 的字词时间戳会直接使用。

普通歌词中的中文按字显示，英文按词显示；没有时间戳时默认一字一拍。吸附只对齐音频起点，保留音频长度。

新手操作手册

从第一段声音到歌词、调音和导出

先做出一个能播放的小作品

第一次使用可先用音效库练习，不用准备音频。上方紫色按钮会根据进度提示下一步，详细操作如下。

  1. 准备声音。左侧点“导入人声 / 音效”，选择一段台词、叫声或录音；也可以点“音效库”，试听后点“加入素材”。素材会出现在左侧，项目仍没有时间轴片段。
  2. 选择并入轨。点素材名称，中间显示波形。拖动波形选一个字或一小段声音，点“试听片段”确认，再点“加入时间轴”。下方人声轨出现音频条，表示这段声音已进入作品。
  3. 编排并调音。点下方音频条，使它有紫色边框，再到右侧“音符调音”点 do / re / mi。点击现有音频条时，音符直接修改它；只选素材时，音符设置新片段的音高，需要再点“添加这个音符”入轨。
  4. 播放并保存。点时间轴左上角 ▶ 听整段作品。觉得合适后，右上角“导出 WAV”输出成品；“保存工程”保存可继续编辑的素材、片段和歌词。
30 秒练习：音效库加入“弹簧 BOING” → 加入时间轴 → 复制两次 → 分别选三条音频，点 do、mi、so → 回到开头播放。搞怪音效可能没有稳定音高，听感与人声不同；想练习唱音符，可换成清晰的单字人声。

“新建作品”清空时间轴和歌词，保留素材库，可撤销恢复。空白作品不会自动播放或加入素材。

选对声音，让包袱更清楚

  1. 左侧点“音效库”，按搞怪、提示、转场、节奏分类浏览，也可搜索名称或用途。点“试听”只听声音；点“加入素材”后才进入左侧素材库，重复添加会定位同一个素材。
  2. 鸭叫适合吐槽和句尾，弹簧适合弹跳动作，错误提示适合答错，提示铃适合灵光一闪，唱片急停适合反转，滚鼓适合揭晓前铺垫，失败长号适合反高潮。
  3. 库中的声音默认选取完整长度；自己的长录音默认先选开头 1.5 秒。拖动中间波形调整范围，或展开“更多：识别文字、自动切片、精确选区”，填写起点和终点。
  4. “识别片段 / 音高”按发声区域找片段，并估计音高；点击识别结果选择一段。“全部切片入轨”将识别到的片段加入人声轨，随后可以删掉不要的。
  5. “语音转文字”识别台词内容，和“识别片段 / 音高”是两种功能。首次转文字需联网下载模型；清晰人声更适合识别，纯音效可能没有文字结果。

这 7 种声音来自 Freesound 的 CC0 素材，已包含在 HTML 中，打开音效库无需联网。每张卡片有作者和来源链接。它们是搞怪剪辑的工具音效，不是 B 站知名人物台词原声；可自行导入你有权使用的台词。

让音频条吸附到每个字

  1. 时间轴上方点“导入歌词”，选择 TXT、LRC 或 SRT；也可以点“粘贴 / 编辑歌词”。例如粘贴“把声音变成旋律”，起点设为 0 秒、每字间隔 0.5 秒，然后点“应用到歌词轨”。
  2. 普通文本按设定间隔排字；LRC / SRT 保留每句时间，将句中的字词均分。增强 LRC 有逐字时间时直接使用。中文按字，英文按词。
  3. 先选左侧素材，在中间选片段，再点下方一个歌词字。中间“对齐选中的歌词”按钮亮起，点击后会把当前选区放到这个字的起点。手机也可以这样操作。
  4. 电脑上可把左侧素材拖到歌词字上，或拖到下方人声轨。开启“歌词吸附”后，靠近文字时间点会高亮并吸附。移动已经入轨的片段也能吸附。
  5. 吸附只改变声音起点，保留声音长度。声音太长会盖住后面的字，请拖片段两端裁短；想自由移动，按住 Alt，或关闭歌词吸附。
歌词吸附优先于节拍吸附。整首歌词早了或晚了，可在歌词编辑器设置整体偏移；没有精确时间的普通歌词，需要自己根据伴奏试听和调整。

按整首歌的调性匹配人声

  1. 左侧点“导入伴奏”。伴奏自动加入背景音乐轨，右侧切到“伴奏匹配”，分析并显示估计调性。调性是整首歌的音阶范围，不是某个时刻的具体旋律。
  2. 检查“参考伴奏”是否选对歌曲。结果不确定时，先试听并点击“确认该调性”，或在“歌曲调性”中手动选已知的大调 / 小调；必要时点“重新识别”。
  3. 开启“入轨 / 移动后自动调音”。此后把人声加入或移动到人声轨时，系统将该片段的估计音高调到歌曲音阶中最近的音。已经排好的片段，点“一键匹配全部人声”，可撤销。
  4. 调性匹配不会自动复制主唱旋律，也不能保证所有长句都好听。建议把人声切成单字或短音节；没有稳定音高的鼓、噪声和音效会保留原音。
  5. 要自己做 do re mi，先关闭自动调音，切到“音符调音”。选中音频条后点音符；目标八度默认中音，太尖可选低音。展开“更多：半音微调与片段音量”可微调或还原。

在中间展开“自动编排 do re mi”，输入例如 do re mi do mi so，点“生成旋律片段”，会按当前 BPM 重复当前选区。BPM 120 表示每拍 0.5 秒；这里不会自动检测歌曲速度。

把片段排好，再交付成品

  1. 拖动音频条改变位置；拖动两端裁剪。点击标尺把播放头移到需要的位置，选中音频条后点“分割 Shift+S”。“复制”重复片段，“删除”移除选中片段，撤销 / 重做可回退编排。
  2. 人声和背景音乐可同时播放。“M”让该轨道静音，轨道滑块控制整轨音量，右侧的片段音量只改选中片段。建议先把背景音乐调小，保证台词能听清。
  3. 时间轴“缩放”只改变显示比例，音频时长不变；水平滚动查看后半段。桌面可上下拖动编辑区和时间轴之间的小横条，双击还原。轨道可以上下滚动，播放和剪辑按钮始终留在外面。
  4. 点“保存工程”下载 JSON 工程，里面包含声音和编排。下次点“打开工程”恢复。打开会替换当前作品，请先保存；“新建作品”不会移除左侧素材。
  5. 点“导出 WAV”得到可导入剪映等编辑器的混音音频。WAV 不包含字幕画面，想做视频还需在视频编辑器配上画面。工程文件用于继续编辑，WAV 用于播放和交付。

快捷键：空格播放 / 暂停；A S D F G H J 对应 do re mi fa so la si；Ctrl+Z 撤销，Ctrl+Shift+Z 重做；Delete 删除；Shift+S 分割。输入文本或打开弹窗时，这些剪辑快捷键不会触发。

遇到问题时按这里检查

为什么按钮是灰色？
先导入或从音效库加入一个声音，再点击素材。导出和播放需要时间轴有片段；“对齐”需要先选一个歌词字。
改了音符，怎么听着没变？
确认选中的是下方音频条，再点音符并播放作品。左侧小 ▶ 试听的是原素材；中间试听片段会按当前选区设置处理。若开启了自动伴奏匹配，后续移动可能再次改音，手动编排时请关闭它。
背景音乐为什么没有识别到调性？
噪声、鼓点、短音效或转调较多的歌曲可能不可靠。选择整首参考伴奏，或手动指定已知调性。系统显示的是估计结果，适合先试听确认。
文字识别一直加载？
首次需要联网下载 Whisper tiny 模型，可先等待。推荐用工具包中的启动程序以本地 HTTP 打开，再重试；音高识别、音效库和手动编排不依赖文字模型。转文字结果可能有误，请手动校对。
导入失败或浏览器变慢？
单个音频限 150 MB、15 分钟，工程限 250 MB。尝试短 WAV / MP3，长录音先在其他工具剪短。大量素材、长混音和大幅移调会增加耗时或改变音色。
界面挤、看不到所有轨道？
桌面拖动中间分隔条调整上下空间；只在轨道区上下滚动查看背景音乐。窗口较窄时页面改为可上下滚动。浏览器缩放过大也会减少可用空间。

音频导入、调音和导出在本机完成；内置音效不需要下载。转文字首次联网获取模型；点击来源链接会访问素材网站。关闭页面前请保存工程。
