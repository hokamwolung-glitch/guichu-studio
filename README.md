# 鬼畜工坊 · Guichu Studio

一个在浏览器里制作鬼畜音频的小工具：导入台词、人声或音效，选择要重复的片段，通过 do / re / mi 调音，再配上背景音乐。底部提供歌词、人声、伴奏时间轴，可拖动、裁剪、对齐和混音导出。

当前工具版本：**1.7.0**。项目仓库：[hokamwolung-glitch/guichu-studio](https://github.com/hokamwolung-glitch/guichu-studio)。仓库现为公开，后续完成并验证的版本会继续同步到这里。

工具打开时是空白工程，**不自动加载素材或示例**。可自行导入声音，也可从内置音效库试听后按需加入。界面采用紫白主题，保留用户提供的学校标识；这是个人工具项目。

## v1.7 新增：逐字时长与按钮改调

导入歌词后，拖人声到某个字上，默认会保持音高伸缩到这个字的时间长度。右侧“一键改调（选中片段）”只处理当前选中的一条人声；导入、拖动和裁剪不会自行改调。

第一次使用建议：导入伴奏和逐字歌词 → 选人声中的一个字 → 拖到对应歌词字 → 试听长度 → 选中这条音频，点击“一键改调”。不满意可以撤销。

原曲逐字时长需要时间戳。增强 LRC 可以提供逐字时间；TXT、普通 LRC 和句级 SRT 的字间长度是估算。点击歌词字，在中间展开“调整选中字词时间”，试听伴奏后输入这个字的开始和结束时间，再点击应用。工具不会凭文本恢复原唱每个字的真实时长。

## v1.6 新增：人声音效库

左侧新增独立的“人声音效库”，可与搞怪音效库切换。启动仍为空白工程，不会自动添加或播放。

### 可以立即使用的真人声音

8 段 CC0 录音已内嵌，可离线试听和“加入素材”：嗯？疑问短声、Hey！回声喊声、真人笑声与吸气、短促大笑、Oh no 失败反应、Hmm 思考声、Yeah 欢呼和 Wow 惊叹。它们是真人录音，不是知名梗台词原声。加入后再点“加入时间轴”，可照常裁剪、调音和导出。

### 你提到的梗与近期参考

已主动收集 20 个梗条目，按近期条目、经典鬼畜与直播反应分类。包括咕咕嘎嘎、康神开播了、爱你老己、哈基米 / 曼波、金坷垃、我要验牌、从夯到拉、我是奶龙、你干嘛、鸡汤来咯、Are you OK、你吼那么大声干什么、乌鸦坐飞机、奥利给、窝窝头、Duang、真香、打工是不可能打工的、我老爸得了 MVP、年轻人不讲武德。前四项有 2026 年发布的参考视频，金坷垃归为经典鬼畜。查证日期为 2026-10-10，页面分类不是当前热度排名；视频发布日期不代表梗诞生时间。

这些条目没有内置原声，不会把通用音效或合成声音冒充原台词。操作如下：

1. 打开“人声音效库”，搜索梗名，或用“近期条目 / 经典鬼畜 / 直播反应”筛选。
2. 点“查看参考视频”在新窗口观看，核对是否是你要的版本。来源页面不自动提取或下载音频。
3. 手头有可使用的原声文件时，点“关联本地原声”，选择 MP3、WAV 等文件。文件会导入并与该条目关联，不会自动入轨。
4. 在中间波形选一个字或一段短句，试听后加入时间轴，或拖素材到歌词字上吸附。
5. 保存工程后，下次打开工程仍可在库中点“选择已关联素材”定位这段声音。同一条目不会反复导入。

未关联的梗条目只有来源和关联入口，不显示假试听按钮。关联不会校验录音内容是否与梗名一致，请自行核对。原声文件只保存在用户自己的工程内；工具发布内容没有用户导入的录音。

完整作者、视频标题及来源见 [音效来源](SOUND_CREDITS.md)。小屏弹窗只滚动卡片列表，顶部切换、搜索和底部说明保持可见。

## v1.5 新增：音效库、详细教程与布局

左侧“音效库”提供 7 种可选声音。音频已经包含在 HTML 中，试听与添加无需联网。剪辑风格参考 B 站梗音效合集，实际录音选自可分发的 Freesound CC0 素材，不是人物台词原声或热门排名。

| 音效 | 适合的剪辑位置 |
| --- | --- |
| 卡通鸭叫 | 吐槽、停顿、一句话结尾 |
| 弹簧 BOING | 弹跳动作、重复动作、滑稽转场 |
| 8-bit 错误提示 | 答错、卡壳、失败 |
| 揭晓滚鼓 | 答案揭晓前铺垫，结尾带镲声 |
| 唱片急停 | 反转、打断、尴尬停顿 |
| 叮！提示铃 | 灵光一闪、答对、句子重音 |
| 失败长号 | 失误结尾、反高潮 |

操作顺序：

1. 点“音效库”，按分类浏览，或搜索名称 / 用途。
2. 点“试听”仅播放该声音，不改变作品；关闭弹窗会停止试听。
3. 点“加入素材”，回到编辑区。声音出现在左侧，并默认选择完整长度。
4. 中间“试听片段”确认声音，然后点“加入时间轴”，才会加入作品。可先裁短滚鼓、长号等较长音效。
5. 再次添加同一音效会定位已有素材，不会重复塞进素材库。可以把同一个素材多次加入时间轴。

所有作者与原始链接见 [音效来源](SOUND_CREDITS.md)。库音效保存进工程后与个人导入声音一样，可恢复、裁剪、变调和导出。短打击音、噪声类音效可能没有稳定音高，不一定适合唱 do re mi。

### 不用准备文件的第一次练习

音效库加入“弹簧 BOING” → 加入时间轴 → 点“复制”两次 → 分别选三条音频，点 do、mi、so → 回到开头播放 → 导出 WAV。想练习更清晰的旋律，换成自己录制的单字人声。

顶部“使用说明”现在有六个章节：入门四步、音效与选区、歌词对齐、伴奏与调音、剪辑与导出、常见问题。每章都说明按钮名称、操作顺序和预期结果，教程里也可直接打开音效库练习。

### 新布局怎么使用

左侧导入人声按钮独占一行，下一行是“导入伴奏”和“音效库”；桌面素材列表单独滚动，导入按钮留在原位。右侧切换“音符调音” / “伴奏匹配”，一次集中处理一种任务；选人声或音效时显示音符，选伴奏时显示匹配。仍可手动切换。

桌面时间轴只滚动轨道区，播放与剪辑按钮不会随轨道滚走。上下空间可拖中间分隔条调整；小屏和手机改为页面纵向滚动。音效库、教程弹窗都有独立滚动区域和明确关闭按钮。

## 下载与启动

### Windows：推荐使用启动脚本

下载并解压本仓库（Code → Download ZIP）。Windows 用户确保下列文件在同一个文件夹，再双击 **启动鬼畜工坊.cmd**：

| 文件 | 用途 |
| --- | --- |
| `index.html` | 完整工具页面，核心编辑功能都在这个文件里 |
| `启动鬼畜工坊.cmd` | Windows 启动入口 |
| `guichu-server.ps1` | 只在本机运行的网页服务 |
| 使用说明 / README | 操作与限制说明 |
| 版本记录 / CHANGELOG | 各版本变化 |

启动后会自动打开浏览器。保持启动窗口开启；关闭启动窗口即可停止服务。脚本默认只监听 `127.0.0.1:18123`，只提供工具页面，不需要账号或在线服务器。

推荐使用 Chrome 或 Edge。工具本身无需安装 Node.js、Python 或模型服务。音频格式是否能读取，也取决于浏览器提供的解码能力。

### 直接打开 HTML

只需要导入、剪辑、调音、混音和导出时，可以直接双击 `index.html`。

语音转文字需要加载模型模块，直接打开文件可能受到浏览器限制；遇到这种情况，请改用启动脚本或本机 HTTP 服务。

### macOS / Linux 或已有本机服务器

将页面放在本机 HTTP 服务中运行即可。如果已安装 Python 3，可在解压目录执行：

```bash
python3 -m http.server 18123 --bind 127.0.0.1
```

然后在浏览器打开 `http://127.0.0.1:18123/index.html`。关闭服务进程即可停止。此方式使用 Python 自带服务器，其目录服务行为与 Windows 随附的单页面启动脚本不同。

## 第一次做作品：跟着这四步

### 1. 导入并试听声音

点击中央或顶部的“导入声音”，也可以点击左侧“导入人声 / 音效”。导入一段自己的台词或录音，点击素材卡片旁的 ▶ 试听。

顶部紫色“下一步”按钮会随作品状态变化。背景音乐和歌词都是可选的，可以稍后添加。

### 2. 选取片段并放进时间轴

点击素材卡片，然后拖动中央波形，选择一个字、一句短台词或一段音效。波形下方显示选区起止时间和长度，点击“加入时间轴”。

如果需要精确控制，展开“更多：识别文字、自动切片、精确选区”，填写起点与终点，或点击识别出的发声片段进行选择。

先从较短的素材做起更容易试听和重复编排。长句中包含多个音符时，拆成多个短片段更适合调音。

### 3. 点音符调音

选中底部一个音频条，再点右侧 do、re、mi、fa、so、la、si：**会直接修改该音频条，并自动试听**。默认八度为中音，可以切换低音或高音。

如果只选了素材，没有选中时间轴音频条，点音符只是准备目标音高并试听，需要再点击“添加这个音符”才能放进时间轴。

想批量重复片段时，展开“自动编排 do re mi”，输入：

```text
do re mi do mi so
```

点击“生成旋律片段”。每个音符按一个节拍排列；如果选区长于一个节拍，会截取到一个节拍。

### 4. 加伴奏、试听并导出

点击左侧“导入背景音乐”，伴奏会自动放入背景音乐轨。播放检查人声和伴奏是否合适，可调节轨道音量或展开片段音量设置。

满意后点击“导出 WAV”。如果还想继续修改，点击“保存工程”；下次“打开工程”恢复素材、歌词和时间轴。

空工程不能播放或导出。工程不会自动保存，关闭页面前请保存需要保留的作品。

## 时间轴怎么编辑

| 操作 | 结果 |
| --- | --- |
| 拖动音频条 | 改变开始时间，可吸附到节拍或歌词起点 |
| 拖动音频条两端 | 裁剪选区，调整要播放的素材范围 |
| 点击时间刻度 | 移动播放指针 |
| 选中片段后分割 | 在片段内部的播放指针处分为两段 |
| 复制 | 增加一个可继续移动、调音的片段 |
| 轨道 M 按钮 | 静音 / 恢复该轨道 |
| 撤销 / 重做 | 恢复或重新应用支持的编排操作 |

人声与背景音乐轨可同时播放，同一轨道内的片段也可以叠加。歌词轨用于定位和对齐，不会直接产生声音。

“新建作品”清空时间轴和歌词，保留素材库，可撤销恢复。“打开工程”会替换当前工程，存在已编辑内容时会提醒先保存。

## 歌词导入与自动对齐

点击时间轴工具栏的“导入歌词”，或用“粘贴 / 编辑歌词”输入文本。中文按字显示，英文按词显示。

### 普通文本 TXT

没有时间戳时，默认每个字词占一个节拍，按导入时的 BPM 计算；编辑窗口可以修改起点和每字间隔。

```text
你好音乐
让声音动起来
```

### 带句子时间的 LRC

```lrc
[00:00.00]你好音乐
[00:02.00]让声音动起来
[00:05.00]一起做节拍
```

句子起点会被保留，句内字词按时间均匀分配。它不是逐字演唱识别，字词位置可能需要调整。

### 增强 LRC 与 SRT

增强 LRC 中的字词时间戳会直接采用，例如：

```lrc
[00:01.00]<00:01.00>你<00:01.50>好
```

SRT 会保留字幕句子的起止时间，再将句内字词分配到该时间段：

```srt
1
00:00:01,000 --> 00:00:03,000
你好音乐
```

### 两种对齐方式

- **拖拽**：把左侧素材卡片拖到某个歌词字词上，自动加入人声轨并对齐起点；移动已有音频条靠近歌词起点，也会吸附。
- **点选**：先选择素材及波形选区，点击下面一个歌词字，再点“对齐”按钮。按钮显示目标字词，手机上也能操作。

歌词吸附优先于节拍吸附，可分别关闭。移动时按住 Alt 可以临时自由移动。点击歌词会移动播放指针；播放时高亮当前字词。

默认开启“歌词时长：保持音高伸缩”。吸附同时对齐起点与字词长度，原始素材及选区起止时间不变。右侧展开“歌词时长：保持音高伸缩”可查看时间轴长度、输入目标秒数、恢复原长，或让已关联的片段批量匹配歌词时长。关闭勾选后，新吸附只改变起点；现有伸缩不会自动清除。

点击歌词字，中间出现“调整选中字词时间”。填写开始与结束时间并应用；开启时长匹配时，与该字关联的人声一起更新位置和长度，音调保持当前设置。增强 LRC 已有逐字时间时会标为逐字时间；普通文本和句级歌词会提示估算。最后一个字缺少结束时间也需要校准。

伸缩采用保持音高的波形重叠算法，播放、试听与 WAV 导出使用同样的目标长度。大幅拉长或压缩可能影响音色，优先选择接近目标长度的单字素材。裁剪会解除歌词关联；分割按时间轴长度对应切开原始选区。工程保存保留目标时长与开关，相关操作支持撤销。

## 跟随伴奏调性：一键匹配人声

### 推荐流程

1. 导入背景音乐，工具在本机采样整首不同位置，估计整体调性。
2. 切到右侧“伴奏匹配”页签检查结果；不确定时确认建议，或手动选择歌曲调性。
3. 导入人声、选择短片段并加入时间轴，或拖到歌词上对齐。
4. 点击底部一条人声音频，再点右侧“一键改调（选中片段）”。按钮在两个调音页签下都可找到。
5. 试听结果，不满意可以撤销。需要批量处理时，在伴奏页签展开“批量操作”，点击“一键匹配全部人声”。

多首伴奏时可以选择参考哪一首，支持 12 个大调和 12 个自然小调。未选中人声、没有确认调性或正在处理时，按钮会禁用并显示提示。没有伴奏也可以手动指定调性。

### 它实际怎么改调

每个片段根据原始选区的基准音高，调到指定调性中最近的音阶音，避免重复点击时累计移调。单片段按钮只改所选人声；长度、位置、歌词关联和音量保留，伴奏不变。

导入、入轨、拖动和裁剪不会触发改调，手动选择的音符保持到你再次点击调音按钮。旧工程即使保存了自动开关，也会按新的手动操作方式打开。

适合单音、短句和鬼畜切片，**不会复制伴奏旋律，也不会逐音修正长句里的所有音符**。没有明确音高的素材保留原音；长句建议先切片。如果手动把伴奏变调，参考调性仍来自原始音频，需要同时手动选择新的歌曲调性。

调性识别是估计，单个音符、鼓点、噪声、复杂混音、转调或半音经过音可能影响结果。请试听确认，必要时手动选调。

算法为本工具实现的频谱峰值音级统计与大小调轮廓相关性，思路参考 [Essentia 官方 Key 文档](https://essentia.upf.edu/reference/streaming_Key.html)。没有调用云端调性识别服务，也没有依赖 Essentia 运行库。

## 语音转文字

选择人声素材，展开“更多：识别文字、自动切片、精确选区”，点击“语音转文字”。接入多语言 Whisper tiny 模型，使用 Transformers.js 在浏览器中运行；第一次需要联网下载模块与模型，之后可利用浏览器缓存。

识别出的词句可点击选择对应音频区域，时间边界可以手动微调。识别期间可继续编辑，也可以取消识别。

模块与模型下载源包括 jsDelivr 和 Hugging Face。网络不可用或下载中断时，文字识别可能失败，核心剪辑、调音和导出仍可使用。请优先使用本机 HTTP 启动方式。

短词、噪声、多人混说和背景音乐会影响识别结果。音效可以估计音高和发声片段，但不一定能转成文字。原始音高不明确时，手动音符调音以 C4 为参考进行相对移调。

实现参考：[Transformers.js 官方语音识别文档](https://huggingface.co/docs/transformers.js/v3.8.1/en/api/pipelines)。文字识别已接入真实模型调用，但测试环境下载模型权重时网络中断，完整转写尚未验证。

## 调整布局与快捷键

较矮的桌面窗口优先给编辑区留空间，只有轨道区上下滚动，播放和歌词工具栏保留在轨道区外。轨道标签随轨道一起滚动；特别矮的窗口改为整体滚动。手机采用纵向布局，歌词对齐可用点选按钮完成。

## 保存、导出与数据处理

- **WAV**：导出当前混合音频，44.1 kHz、16 位、立体声；不会写入歌词字幕。
- **工程 JSON**：包含音频本身、片段、歌词、轨道参数、调性设置，文件可能较大；仅保存布局高度不能代替保存工程。
- **本机处理**：音频编辑、音高识别、调性分析与混音在浏览器内运行，工具没有用于上传音频的后端。
- **联网部分**：语音转文字首次需要请求外部模块和模型文件；项目代码的发布更新与使用者的本机音频工程分开。

导入并不等于备份素材。关闭页面或刷新前，请保存需要保留的工程。

## 常见问题

**导入后没有音频条？** 人声导入后先成为素材，需要点击“加入时间轴”或拖入轨道。背景音乐导入后会自动入轨。

**点了 do / re / mi，为什么导出没有变？** 先确认是否选中了底部音频条。只选素材时是试听，需要再点“添加这个音符”。

**什么时候会改调？** 选中片段后点击“一键改调”，或主动点击音符、半音等调音控制。拖动、入轨和裁剪不会改调。

**伴奏调性识别错了？** 切到右侧“伴奏匹配”页签，手动选择正确调性；有多首伴奏时也要检查参考来源，然后重新匹配。

**歌词和声音重叠？** 开启歌词时长匹配，再对齐到歌词字，或批量匹配已关联片段。歌词自身有重叠时，先校准字的开始 / 结束时间。关闭匹配时可自行裁剪。

**文字识别一直加载或失败？** 改用启动脚本，检查 jsDelivr 和 Hugging Face 是否可访问，必要时取消后重试。其他编辑功能不依赖模型下载。

**打不开音频？** 浏览器可能不支持该文件的实际编码。尝试转换为 WAV 或 MP3 后再导入，并检查大小和时长。

**界面太挤？** 拖动编辑区 / 时间轴分隔条，双击可还原；也可调整浏览器缩放。较矮窗口允许时间轴或页面滚动。

**有没有可选鬼畜素材？** 内置 7 种音效和 8 段真人录音，分别从“音效库”或“人声音效库”试听并加入。梗条目提供来源与本地关联入口；不会自动入轨。

## 实现与验证

核心是单个 HTML 文件，不需要构建步骤：Web Audio 负责解码、播放与混音，Web Worker 负责音高分析、频谱变调和调性估计。语音转文字单独使用模型 Worker。

已经通过实际浏览器验证的行为包括导入、片段选择、音符调音、播放、剪辑、撤销重做、旋律生成、歌词解析与拖拽吸附、手机点选对齐、WAV 导出、工程保存恢复、旧工程兼容，以及桌面分隔条和多尺寸布局。

音频数值测试包括：220 Hz 测试音移调 -12 / +7 / +12 半音后约为 110.00 / 329.65 / 440.11 Hz；短合成元音调至 mi 后约 329.62 Hz，时长保持不变。调性测试覆盖合成 C / G 大调、A 小调旋律及带泛音多声部和弦。

新增验证：1 秒的 220 Hz 声音伸缩到 0.25 / 0.5 / 1.5 / 2 / 4 秒，输出样本数准确，音高约 220.01–220.23 Hz；立体声比例保持。实际浏览器验证了歌词拖动、逐字校准、时长开关、伸缩后裁剪分割复制、撤销、工程恢复、单片段按钮改调、旧自动设置迁移及 WAV 渲染。

这些验证不代表所有真实歌曲都能正确识别，也不代表所有设备上的浏览器都已测试。完整语音转写尚未验证，相关限制见上文。

版本变化见 [版本记录](版本更新.md)。反馈问题时，请描述浏览器、操作步骤、预期结果与实际结果；可以提交自己有权分享的短测试素材，避免在公开 Issue 中附带私人录音或完整个人工程。
