# 鬼畜工坊

当前版本：**1.4.0**。每个完成的新版本都会同步到 GitHub 私有仓库 [guichu-studio](https://github.com/hokamwolung-glitch/guichu-studio)。

下载并解压本仓库（Code → Download ZIP）。Windows 用户双击“启动鬼畜工坊.cmd”，会自动在默认浏览器打开工具。推荐最新版 Chrome 或 Edge。无需安装，音频在浏览器本地处理；保持启动窗口开启，关闭该窗口即可停止本机网页服务。

如果只需要剪辑、调音和混音，可以直接打开“index.html”。本机启动脚本只监听 `127.0.0.1:18123`，只提供工具 HTML 页面。

## 第一次使用

打开页面时素材库、歌词和时间轴为空。先导入自己的声音，顶部四步提示会引导你完成第一段作品，紫色“下一步”按钮根据当前作品状态变化。

1. **选声音**：点击中央或顶部“导入声音”，也可以点击左侧“导入人声 / 音效”，再点卡片旁的 ▶ 试听，点击卡片选中。
2. **拖到歌词**：拖动波形选取片段后，点击“加入时间轴”。需要对齐歌词时，点击下方一个歌词字，再点击“对齐”按钮；也可以拖动素材到字上。导入自己的歌词时，点击“导入歌词”或“粘贴 / 编辑歌词”。
3. **点音符**：选中下方音频条，再点右侧 do、re、mi 等音符，立即修改并自动试听。仅选中素材时，点音符是预览，需要点击“添加这个音符”才能加入时间轴。中音八度为默认推荐。
4. **导出**：点击“试听整个作品”确认效果，再点击“导出 WAV”。“保存工程”可以保存素材、歌词和编排，下次打开继续做。

点击“新建作品”会清空时间轴与歌词，保留素材，可撤销恢复。

## 素材导入与进阶操作

可以导入自己的台词、人声、音效和背景音乐。人声会自动识别发声片段与音高；背景音乐自动添加到独立伴奏轨。

识别、手动选区、批量旋律和半音 / 音量微调默认折叠，展开相应设置即可使用。中央波形可拖动选择区域；在底部拖动音频条移动、拖两端裁剪，选中后可分割、复制、删除、撤销与重做。

## 跟随歌曲调性自动改调

1. 左侧点击“导入背景音乐”，工具会在本机对整首不同位置进行采样，估计整体调性。右侧“跟随伴奏调性”面板显示识别建议。
2. 确认识别结果。若不确定，会提示你确认建议或手动选调；支持 12 个大调和 12 个自然小调。多首伴奏时，选择要参考的那首。
3. 导入人声或音效。开启“入轨 / 移动后自动调音”后，将选区加入时间轴、拖素材到歌词或人声轨、移动或裁剪已有音频条，都会按参考调性自动匹配。
4. 已经编排的作品可点击“一键匹配全部人声”，统一处理所有人声轨片段。这个按钮也能在自动开关关闭时主动执行匹配，操作可撤销。
5. 播放试听，满意后导出 WAV。调性、参考伴奏和自动开关会随工程保存，旧版本工程仍可打开。

每个片段根据原始选区的基准音高，调到该调性中最近的音阶音，避免重复移动时累计移调；保留片段长度、歌词关联、音量和位置，伴奏本身不被自动改调。手动选择的音符会在下一次移动或入轨时重新匹配；希望保留手动音符时，请关闭自动开关。

匹配适合单音或短句鬼畜切片，不会复制歌曲旋律，也不会逐音修正长句中的全部音符。长句建议先用切片功能拆开。没有明确音高的素材会保留原音；单个音符、鼓点或噪声不足以判断整首调性时，需手动选调。估计可能受混音、转调和半音经过音影响，应试听确认。若手动把伴奏变调，参考调性仍来自原始音频，请同时手动选择新的歌曲调性。

识别采用本工具实现的频谱峰值音级统计与大小调轮廓相关性，未依赖云端识别。算法思路参考 [Essentia 官方 Key 文档](https://essentia.upf.edu/reference/streaming_Key.html)。已验证合成 C / G 大调、A 小调旋律及带泛音的多声部和弦，尚不能据此保证所有真实歌曲都识别正确。

## 歌词导入与自动吸附

点击底部“导入歌词”，支持 TXT、LRC、增强 LRC 和 SRT；也可以通过“粘贴 / 编辑歌词”直接粘贴文本。歌词会出现在人声轨上方，中文按字显示、英文按词显示。

- TXT 没有时间戳时，默认每个字词占一个节拍；导入时按当前 BPM 计算。
- LRC、SRT 保留句子的时间，并将句内字词均匀分配。增强 LRC 中的字词时间戳会直接使用。这些字词时间不等同于实际演唱的逐字识别，可在编辑窗口调整整体偏移。
- 手机或不方便拖动时，先选素材并调整波形选区，点一个歌词字，再点“对齐”按钮。按钮会显示目标文字，精确对齐起点并保留时长。
- 素材库的音频可拖到某个字词上，自动加入人声轨并对齐该字词的起点；也可以拖到人声轨中靠近文字的位置。移动已有音频条靠近歌词起点，同样会吸附，并高亮对应文字。
- “歌词吸附”优先于“节拍吸附”，可单独关闭。移动时按住 Alt，可临时自由移动。
- 点击字词可移动播放指针；播放时会高亮当前歌词。吸附仅对齐开始时间，保持原音频长度。
- 编辑窗口可以修改歌词、起点 / 整体偏移和每字间隔，也可以清空歌词。导入、清空和吸附支持撤销。
- 保存工程会同时保存歌词与音频关联；新版本兼容原有工程。WAV 仅导出音频，不写入歌词字幕。

歌词文件最大 1 MB，最多 5000 个字词，时间范围最长 15 分钟。

## 语音转文字说明

选择人声素材后，展开“更多：识别文字、自动切片、精确选区”，点击“语音转文字”。使用多语言 Whisper tiny 模型，首次需要联网加载 Transformers.js 和模型文件，后续使用浏览器缓存。点击识别出的词句即可选择对应音频区域，边界可以手动调整。

识别期间可继续编辑，也可点击“取消文字识别”。模型下载源为 jsDelivr 和 Hugging Face；如果连接不可用，文字识别无法完成，其他音频编辑功能仍可使用。请通过“启动鬼畜工坊.cmd”使用文字识别，避免直接打开 HTML 时浏览器对模型模块的加载限制。

语音识别结果与时间戳是模型估计，短词、嘈杂声音、多人混说和背景音乐可能降低准确度。文字识别仅适合语音；音效可以进行片段和音高识别。没有明确音高的声音，以 C4 为参考进行相对移调。

实现依据：[Transformers.js 官方语音识别 API 文档](https://huggingface.co/docs/transformers.js/v3.8.1/en/api/pipelines)。

## 快捷键与限制

- 空格：播放 / 暂停；A S D F G H J：do re mi fa so la si。
- Shift+S：在播放指针处分割选中片段；Delete：删除。
- Ctrl+Z：撤销；Ctrl+Shift+Z：重做。
- 单个音频文件最多 150 MB、15 分钟；文字识别最多 3 分钟。WAV 输出为 44.1 kHz、16 位、立体声。
- 变调保持时长，音符自动调音范围为 ±36 半音；大幅移调可能改变音色。快速旋律编排每个音符占一个节拍，长选区会截取到一个节拍。
- 工程不会自动保存，关闭页面前请使用“保存工程”。工程文件包含音频本身，可能较大。

## 已验证情况

已通过真实浏览器验证空白启动、中央导入入口、随进度变化的下一步按钮、撤销后引导恢复、手机点选歌词对齐，以及：音频导入、音高识别、音符调音、保留时长、播放、剪辑、撤销重做、批量旋律、立体声 WAV 导出、工程保存与恢复，以及手机宽度布局。

测试音 220 Hz 移调 -12 / +7 / +12 半音，结果约 110.00 / 329.65 / 440.11 Hz；0.45 秒合成元音调至 mi 后约 329.62 Hz，时长保持 0.45 秒。

文字识别已接入真实模型调用，但本次测试环境在下载模型权重时网络中断，完整转写尚未验证。工程中附带的演示素材是合成元音和节拍，不是实际语音录音。
